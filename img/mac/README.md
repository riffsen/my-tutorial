## 拍照注意

- **遮掉隐私信息**：手机号、邮箱、余额以外的账户信息、API Key（`sk-` 开头）一律打码或避开。
- 用系统截图：`⌘ + ⇧ + 4` 区域截图，`⌘ + ⇧ + 5` 窗口截图（会带阴影，好看一些）。
- 建议宽度 1400–1600 px 左右就够，别整张 5K 截图直接塞进来。

## 不需要重拍的

客户端内部界面两平台一模一样，直接复用 `img/` 里的 Windows 截图：欢迎页、注册页、授权成功页、设置引导（截图 08–11）、设置 → 账号与余额、收银台、用量信息、模型价格、选模型的截图（截图 16）、主界面（截图 17）。

**例外：截图 18 不能复用。** 它里面写着 `D:\work\Test1\hello.txt` 这种 Windows 路径，Mac 上路径是 `/Users/…`，对不上。用上面的 `04-选择工作区文件夹.png` 代替。
